Respostas para as principais questões sobre meu trabalho e processo.

Atuo como desenvolvedor Front-end e designer de interfaces. Uno estrutura visual, responsividade, acessibilidade e código para transformar necessidades em experiências web claras e consistentes.
Minha base é HTML, CSS e JavaScript, com Git e GitHub no fluxo de trabalho e Figma na construção de interfaces. Os cases também mostram experiências com React, Next.js, TypeScript, Firebase e APIs de IA.
Landing pages, portfólios, dashboards, páginas institucionais e experiências web interativas. Cada projeto é pensado para funcionar bem em desktop e mobile, com hierarquia visual e chamadas para ação evidentes.
Começo entendendo o objetivo e o conteúdo. Depois organizo a hierarquia, defino a direção de interface, implemento os componentes e valido responsividade, legibilidade, navegação por teclado e comportamento dos links.
Busco oportunidades de nível júnior em Front-end, Desenvolvimento Web, UI Design e Web Design. Também considero projetos em que eu possa contribuir da definição visual à implementação da interface.
